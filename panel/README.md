# Painel KP HOSTS

Base para a futura área do cliente.

Funções previstas:
- login/cadastro
- lista de servidores
- status online/offline
- iniciar/parar/reiniciar
- console
- arquivos
- backups
- seleção de versão
- uso de CPU/RAM/disco

O painel deve chamar a API central, nunca executar comandos diretamente no navegador.
